### F5.1.1

为了简单起见，我没有使用位线和字线来搭建rom，而是使用constant和多路选择器。而且这里，由于pc是8位的，理论上来说，rom的大小应该是256\*8，但是内置多路选择器select bit最多为5位。由于我注意到，数列求和的指令总共只有8条，所以我选择截取pc的后3位来做地址，这样rom的大小是8\*8（其实如果这样实现的话，理论上还需要比较前5位为0，否则实际上这8条指令会等效循环并填满256个word，例如addr为8的指令会和addr为0的指令相同）。
