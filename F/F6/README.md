### F6.1.1

由于10无法被单个新li指令表达，所以需要两条li和一条add指令

```
10000110    # 0: li r0, 8
10010010    # 1: li r1, 2
00000001    # 2: add r0, r0, r1
10010000    # 3: li r1, 0
10100000    # 4: li r2, 0
10110001    # 5: li r3, 1
00010111    # 6: add r1, r1, r3
00101001    # 7: add r2, r2, r1
11111001    # 8: bner0 r1, -2
11000011    # 9: bner0 r3, 0
```
